# 2026年度員工特別休假實施辦法

## 1. 目的
為落實本行勞工福利政策，保障員工休息權益，並符合勞基法之相關規定，特訂定本辦法。

## 2. 適用對象
本行所有編制內之正職員工。

## 3. 特別休假天數標準
員工在行連續服務滿一定期間者，每年應依下列規定給予特別休假：

| 服務年資 | 特別休假天數 |
| :--- | :--- |
| 6個月以上未滿1年 | 3日 |
| 1年以上未滿2年 | 7日 |
| 2年以上未滿3年 | 10日 |
| 3年以上未滿5年 | 14日 |
| 5年以上未滿10年 | 15日 |
| 10年以上 | 每一年加給1日，加至30日為止 |

## 4. 請假程序
1. 員工應於特別休假日前 3 日，透過內部 HR 系統提出申請。
2. 須經單位主管核准後始得休假。
3. 為確保業務正常運作，同一單位同一時間休假人數不得超過該單位總人數之 20%。

## 5. 未休假處理
特別休假於年度終結或契約終止而未休者，其應休未休之天數，本行將依工資發給標準折算為工資發給。
