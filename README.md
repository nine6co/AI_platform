# AI Chatbot Platform Portal

這是一個專為金融科技或企業內部設計的 **生成式 AI 應用入口平台 (Generative AI Application Portal)**。本專案強調專業、簡潔的介面美學與直覺的操作體驗。

## 🎨 設計哲學與風格 (Design Identity)

- **配色方案 (Palette)**:
  - **Primary**: `#000093` (深藍) - 代表專業與穩重的科技感。
  - **Background**: `#F3F4F6` (淺灰) - 提供清晰的視覺深度。
  - **Surface**: `#FFFFFF` (純白) - 用於卡片與工作區，強調資訊主體。
- **風格**: **Flat UI (平面化設計)**。完全捨棄漸層與玻璃擬態，利用細膩的邊框 (`border-border`) 與陰影 (`shadow-sm`) 來建立層次感。
- **字體**: 使用 `Plus Jakarta Sans` 提供現代化且易讀的文字表現。

## 📂 核心功能頁面說明

### 1. 應用入口首頁 (`index.html`)
- **智慧導覽側邊欄**:
  - 支援 **手動收合 (Toggle)**：收合時僅保留 Icon，展開時顯示 Icon+文字。
  - **二級選單邏輯**：主入口分類預設收合，採 **Hover 自動展開** 模式顯示子功能（如：文件翻譯、語音會議記錄）。
- **工具卡片佈局 (Card-Based UI)**:
  - 以卡片形式呈現不同 AI 工具（語音記錄、文件翻譯）。
  - 具備微動畫反饋：Hover 時卡片會輕微上浮 (`-translate-y-1`) 並加深邊框色。
- **搜尋與管理**:
  - 全域關鍵字搜尋框。
  - 底部分頁控制與筆數顯示，具備良好的水平擴展性。

### 2. 文件翻譯功能頁 (`translation.html`)
- **路徑導航 (Breadcrumbs)**: 頂部提供清晰的連結，方便使用者快速返回主入口。
- **雙選單操作面板**:
  - 左側功能分頁（輸入設定 / 上傳紀錄）區隔任務執行與歷史查詢。
- **表單處理**:
  - **檔案上傳區塊**: 支援多格式 (.docx, .pdf, .pptx 等) 的拖曳上傳/點擊選擇。
  - **智慧語言選擇**: 統一樣式風格的下拉選單，具備 Placeholder 灰階區隔與必填驗證提示。
- **狀態控制**: Submit 與 Download 按鈕根據任務狀態進行 UI 切換。

## 🛠 技術規格

- **前端框架**: 採用 **Tailwind CSS (CDN)** 進行快速樣式構建。
- **圖示庫**: 使用 **Lucide Icons** 提供一致的線條風格。
- **互動邏輯**: 使用原生 JavaScript 實作側邊欄收合、子選單 Hover 展開與頁面流轉邏輯。

## 🤖 品牌元素 (Mascot)
側邊欄 Logo 區塊包含一個客製化的機器人 Mascot SVG，設計參考了華南風格的紅色標誌元素，並透過細膩的繪製（天線、微笑、腮紅）增加產品的親和力。
